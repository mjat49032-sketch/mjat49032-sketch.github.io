How to install

  1. Tap Download APK and open the file when it finishes.
  2. If Android asks, allow Install unknown apps for your browser.
  3. Open OriginCC and allow Display over other apps. The panel needs it to float above your screen.
  4. Turn on the OriginCC Accessibility service. It is used only to capture the screen for the blur effect.
